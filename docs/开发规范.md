# 开发规范

改卡面、拆卡动效或音效时先看这份。同一表现只写一处，见「复用」。产品范围和页面流程见 `docs/prd.md`。

五个品级是 `N`、`R`、`SR`、`SSR`、`SECRET`。名称分别是普通、稀有、超稀有、特级、秘藏。新增表现必须五档都能分出来，不能只把高等级做得更亮、更响。

## 复用

同一种卡面、手势、品级色或声音，全项目只写一处。新页面接已有组件，用参数区分场合，不另写一份。改共享实现时，用到它的页面一起看。

| 表现 | 只写在 | 用在 |
| --- | --- | --- |
| 卡面。风格按卡包定，可以再加 | `CardVisual`。二十四节气的画心在 `SolarScene` | 卡包详情、图鉴、检视、拆卡扇面、高等级开卡 |
| 小卡与检视同一版式 | `.card-fit`：按 400px 排版，再缩进格子 | 卡包详情、图鉴 |
| 拖拽倾斜、滚轮缩放 | `useCardPose`。只通过初始角度区分：检视侧面打开，高等级开卡正面开始 | 检视、高等级开卡 |
| 指针跟随的高光位置 | `usePointerTilt` | 扇面、卡包，以及静止大卡上的高光 |
| 品级色 | 「品级色」一节列出的几处一起改 | 商店、卡面、拆卡演出 |
| 翻开声、撕开声 | `src/audio/soundEngine.ts` | 拆卡 |
| 抽卡与保底 | `src/data/pull.ts` | 拆卡 |
| 库存、图鉴、金币 | `src/store/useGameStore.ts` | 各页面 |

循环扫光 `.card-foil` 只在 `CardVisual` 里判断：调用方传入 `sweep`，且品级是特级或秘藏，才画。检视和高等级开卡都传 `sweep`，页面里不再判断品级。图鉴、卡包列表和拆卡扇面不传。静止时高光和绢丝透明，指针在卡上才亮。超稀有翻开时的扫光属于演出，不走 `.card-foil`。

禁止：

- 把悬停跟随和拖拽缩放并进同一个 hook。前者是指针移动，后者是按住拖动和滚轮。
- 给拆卡扇面套 `.card-fit`。扇面的卡要翻面，缩放会把 3D 翻面压扁。翻开期间祖先上的 `transform` 和 `filter` 见「拆卡动效」。

## 卡面

卡面风格按卡包定，可以再加，不收成固定的几种。新风格加在 `CardVisual` 上，用参数区分，不另做一套卡。列表、图鉴、检视、扇面和高等级开卡共用这一张。一套卡包只用一种风格。

不论风格，这些不变：

- 比例 208/296。字号用 `cqi`，按 400px 宽排版，最小一档约 `3.3cqi`。小卡走 `.card-fit`。拆卡扇面不套这层缩放，见「复用」。
- 底部左侧的编号，和品级，从卡牌数据印出，不画进图里。编号用 `formatSerial`，形如 `NO. 012 / 024`。品级颜色走「品级色」。其余文字和图可以印在界面上，也可以画进图里，由这一套的风格决定。
- 高光、扫光、翻面仍是这一张卡上的层。
- 新卡角标是获得状态，可以叠在任何风格上。套印的字跟卡包走，朱红和品级色不随画面风格改。

例如整张正面可以是一张生成的图，卡名、三候、题款和画都在图里，界面就只留编号和品级。这只说明图可以占多大，不是第二种固定样式。

### 二十四节气

这一套是册页。图只占中间的画心，节气名、三候、题款也印在册页上。画心里不写字、不盖印、不加边框。

画心是 `src/assets/solar/{场景 id}.jpg`，由 `SolarScene` 按文件名取用，铺满画框时 `object-fit: cover`。不按 400px 排，浏览器的最小字号会把三候和题款挤乱。

节气名是 `h3`（`.leaf-name`）。页面上的标题选择器写成直接子元素，例如 `.pack-detail-group > h3`。写成后代选择器会套到卡名上，下划线会跑到字旁边。

### 画心卡

生肖双相、渊柜、窗台花房、棉绒马戏、末班电车、鞘翅匣、第二口、未发行、发条匣各用一种画面，数据在 `src/data/plates.ts`。整张正面是 `src/assets/plates/{系列}/{两位编号}.jpg`，由 `PlateArt` 按路径取用。卡名、一句题款、编号和品级印在画面下沿，不画进图里。渊柜的画面只有标本，卡面不印卡名和题款，只印编号和品级；卡名和题款在检视里，卡名也在开卡演出里。卡背上面是开缄社的印和社名，下面是这一套的名称和短码。

## 品级色

五档各用一种矿物色，色相不能重叠。

| 品级 | 颜料 | 界面亮色 `RARITY_TONE` | 卡面印色 `--grade` | 卡边 `--rim-color` |
| --- | --- | --- | --- | --- |
| 普通 `N` | 松烟灰 | `#b7aea2` | `#7a7268` | `#9a9186` |
| 稀有 `R` | 花青 | `#7eb6de` | `#1e4f78` | `#3d7eae` |
| 超稀有 `SR` | 石绿 | `#5dccb0` | `#146b56` | `#1f9a78` |
| 特级 `SSR` | 泥金 | `#f0d48a` | `#8a6424` | `#e0c37a` |
| 秘藏 `SECRET` | 青莲 | `#d7c4ef` | `#5c3478` | `#c4b0dc` |

`RARITY_TONE` 用在深色界面上的字和权重条，要亮。卡面印、边、角标用更深的同色相，保证浅纸上看得清。

禁止：

- 两个品级同属红、金或同一个冷色。超稀有用石绿，秘藏用青莲，不能再一起做成朱红。
- 秘藏边光改回泥金。泥金只属于特级。
- 用彩虹、全息彩边或季节纸色代替品级色。季节只改纸色和画意，不改品级。纸色见「季节色」。

朱红 `#8e3a38` 只留给印记：品牌印、卡包封、卡背框、卡面小印 `--seal`、新卡角标。品级的边、角标、品级字、翻开光、碎光、摇包光晕都不许用这枚红。

改一个品级的颜色时，下面几处一起改，只改一处会在商店、卡面和拆卡演出里变成不同色：

- `src/data/catalog.ts` 的 `RARITY_TONE`
- `src/index.css` 里该品级的 `--grade`、`--rim-color`、角标、品级字、摇包光晕
- `src/index.css` 里 `.reveal-*`、`.grade-*`、`.callout-*`、撕开闪光
- `src/components/Atmosphere.tsx` 的 `GRADE_LOOK`

## 季节色

这组纸色用于二十四节气的册页。纸色、墨色、画意只跟季节走，写在 `--paper`、`--ink`、`--pigment`。不代替品级色。别的卡面风格可以不用这套纸色。

| 季节 | 纸 `--paper` | 墨 `--ink` | 画意 `--pigment` |
| --- | --- | --- | --- |
| 春 | `#f4efe6` | `#243028` | `#3f6b56` |
| 夏 | `#f7f1e6` | `#3a2a1c` | `#c4622d` |
| 秋 | `#f3eadc` | `#2c241c` | `#a15c32` |
| 冬 | `#eef2f4` | `#1c2836` | `#3d6280` |

秘藏目前只有冬至，季节选择器只配了冬季。以后别的季节出现秘藏时，补上对应的 `.rarity-SECRET .card-front.is-leaf.season-*`。

## 拆卡动效

撕开时看这一包的最高品级。翻开时看这一张自己的品级。全部翻开从左到右逐张来，翻完一张再等一拍，高等级停得更久，让这一张的光和声音落完。

| 品级 | 翻开 | 舞台 |
| --- | --- | --- |
| 普通 | 最快，一圈淡环 | 无印戳，不压暗，不震屏 |
| 稀有 | 稍慢，两圈亮环 | 无印戳，不压暗，不震屏 |
| 超稀有 | 石绿环、印戳、扫光 | 屏幕出现「超稀有」，轻震 |
| 特级 | 泥金环、光柱、印戳、扫光 | 屏幕出现「特级」，中震 |
| 秘藏 | 青莲环再套一圈，光柱、印戳、扫光，翻得最慢 | 屏幕出现「秘藏」，重震，压暗最久 |

卡在 `.tcg-card` 上用 `rotateY` 翻面。光环、光柱、印戳、扫光放在同级元素上。翻开期间不要给 `.tcg-card` 的祖先加 `transform` 或 `filter`，否则 3D 翻面会扁掉。

`prefers-reduced-motion: reduce` 时翻面几乎立刻完成。碎光、震屏、光柱和循环扫光不做。印戳和品级字仍留在画面上。检视和高等级开卡不再做倾斜过渡。

## 同一拍

高等级卡飞到画面正中的时刻以 `src/gradeHit.ts` 为准，现在是 420ms。演出、点蒙层的解锁、余烬和翻开声都读这一拍，CSS 用 `--hit`。

下面几处要和它相同，只改一处会让光和声音错开：

- `GRADE_HIT_MS`、`GRADE_HIT_SEC`
- `.grade-show`、`.grade-front` 的 `--hit`
- `.card-foil` 动画里 `--hit` 的回退值

## 关闭

检视和卡包详情：点蒙层、点关闭按钮，或按 Esc。点卡片本身不关闭。

高等级开卡：点蒙层或按 Esc。卡上的点击、拖拽和滚轮不关闭。落地（见「同一拍」）之后才接受关闭。拖出卡外再松手，不当成点了蒙层；按下时要抓住指针。

## 拆卡音效

音效只在 `src/audio/soundEngine.ts` 里用 Web Audio 合成，不加载外部音频。静音开关关掉后，`flip` 和 `burst` 都不发声。

五个品级的翻开声必须是五种做法，不能只改音高：

| 品级 | 翻开 `flip` | 撕开 `burst`（按包内最高品级） |
| --- | --- | --- |
| 普通 | 短纸响 | 短和弦 |
| 稀有 | 两声拨弦 | 短和弦 |
| 超稀有 | 一声闷击后音往上走 | 闷击加更亮的和弦 |
| 特级 | 闷击、上滑音、金弦 | 闷击、上滑音、更长的和弦 |
| 秘藏 | 低鸣、长上滑、钟鸣 | 最低的闷击、最长的上滑和和弦 |

撕开的光和碎光跟这包最高品级走，颜色仍用「品级色」，不另起一套。
