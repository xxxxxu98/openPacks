# 开发规范

改卡面、拆卡动效或音效时先看这份。产品范围和页面流程见 `docs/prd.md`。

五个品级是 `N`、`R`、`SR`、`SSR`、`SECRET`。名称分别是普通、稀有、超稀有、特级、秘藏。新增表现必须五档都能分出来，不能只把高等级做得更亮、更响。

## 品级色

五档各用一种矿物色，色相不能重叠。

| 品级 | 颜料 | 界面亮色 `RARITY_TONE` | 卡面印色 `--grade` | 卡边 `--rim-color` |
| --- | --- | --- | --- | --- |
| 普通 `N` | 松烟灰 | `#b7aea2` | `#7a7268` | `#9a9186` |
| 稀有 `R` | 花青 | `#7eb6de` | `#1e4f78` | `#3d7eae` |
| 超稀有 `SR` | 石绿 | `#5dccb0` | `#146b56` | `#1f9a78` |
| 特级 `SSR` | 泥金 | `#f0d48a` | `#8a6424` | `#e0c37a` |
| 秘藏 `SECRET` | 青莲 | `#d7c4ef` | `#5c3478` | `#c4b0dc` |

`RARITY_TONE` 用在深色界面上的字和权重条，要亮。卡面印、边、角标用更深的同色相，保证浅纸上看得清。

禁止：

- 两个品级同属红、金或同一个冷色。超稀有用石绿，秘藏用青莲，不能再一起做成朱红。
- 秘藏边光改回泥金。泥金只属于特级。
- 用彩虹、全息彩边或季节纸色代替品级色。季节只改纸色和画意，不改品级。

朱红 `#8e3a38` 只留给岁印：品牌印、卡包封、卡背框、卡面小印 `--seal`、新卡角标。品级的边、角标、品级字、翻开光、碎光、摇包光晕都不许用这枚红。

改一个品级的颜色时，下面几处一起改，只改一处会在商店、卡面和拆卡演出里变成不同色：

- `src/data/catalog.ts` 的 `RARITY_TONE`
- `src/index.css` 里该品级的 `--grade`、`--rim-color`、角标、品级字、摇包光晕
- `src/index.css` 里 `.reveal-*`、`.grade-*`、`.callout-*`、撕开闪光
- `src/components/Atmosphere.tsx` 的 `GRADE_LOOK`

## 拆卡动效

撕开时看这一包的最高品级。翻开时看这一张自己的品级。全部翻开从左到右逐张来，翻完一张再等一拍，高等级停得更久，让这一张的光和声音落完。

| 品级 | 翻开 | 舞台 |
| --- | --- | --- |
| 普通 | 最快，一圈淡环 | 无印戳，不压暗，不震屏 |
| 稀有 | 稍慢，两圈亮环 | 无印戳，不压暗，不震屏 |
| 超稀有 | 石绿环、印戳、扫光 | 屏幕出现「超稀有」，轻震 |
| 特级 | 泥金环、光柱、印戳、扫光 | 屏幕出现「特级」，中震 |
| 秘藏 | 青莲环再套一圈，光柱、印戳、扫光，翻得最慢 | 屏幕出现「秘藏」，重震，压暗最久 |

卡在 `.tcg-card` 上用 `rotateY` 翻面。光环、光柱、印戳、扫光放在同级元素上。翻开期间不要给 `.tcg-card` 的祖先加 `transform` 或 `filter`，否则 3D 翻面会扁掉。

`prefers-reduced-motion: reduce` 时翻面几乎立刻完成，碎光和震屏不做，印戳和品级字仍要留在画面上。

## 拆卡音效

音效只在 `src/audio/soundEngine.ts` 里用 Web Audio 合成，不加载外部音频。静音开关关掉后，`flip` 和 `burst` 都不发声。

五个品级的翻开声必须是五种做法，不能只改音高：

| 品级 | 翻开 `flip` | 撕开 `burst`（按包内最高品级） |
| --- | --- | --- |
| 普通 | 短纸响 | 短和弦 |
| 稀有 | 两声拨弦 | 短和弦 |
| 超稀有 | 一声闷击后音往上走 | 闷击加更亮的和弦 |
| 特级 | 闷击、上滑音、金弦 | 闷击、上滑音、更长的和弦 |
| 秘藏 | 低鸣、长上滑、钟鸣 | 最低的闷击、最长的上滑和和弦 |

撕开的光和碎光跟这包最高品级走，颜色仍用上一节的色，不另起一套。
