# SimpleMkt 3D 拆卡游戏产品文档（PRD · 工程化版）

## 1. 产品概述

### 1.1 产品定位

**SimpleMkt** 是一款基于 **React + TypeScript + Vite + Tailwind CSS** 工程化架构构建的 3D 光学拆卡收藏游戏。产品以深色光学展厅与哑光黑微纹理卡包开箱为核心，融合实时 3D 透视倾斜、封口弹性形变撕裂、锯齿毛边裂口金光、内部金光爆发与烟雾光柱、全息彩虹烫金卡面、眼神追踪角色及 Web Audio 程序化音效合成，提供无广告、高动效、可本地持久化的完整开箱与收藏体验。

### 1.2 核心设计理念

- **极简导航，动效拉满**：仅保留 **首页、商店、拆卡室、图鉴** 四大核心页面，精简冗余文案与商业广告模块，将视觉与交互重心聚焦在拆卡物理反馈与全息光影表现上。
- **工程化模块化拆分**：按类型、数据、音频、状态、自定义 Hook、组件与页面分层组织代码，便于后续扩展新卡池、新卡面或接入后端接口。
- **零外部音频与图片依赖**：音效由 Web Audio API 实时合成，材质纹理、全息光栅与奇幻图标均通过 CSS 与组件化渲染实现。

## 2. 工程架构与模块划分

项目采用标准 Vite + React + TypeScript 工程结构：

| 目录 / 文件                     | 职责说明                                                                                      |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| `src/types/game.ts`             | 定义路由类型、稀有度枚举、奇幻图案类型、卡牌结构、抽卡实例、卡包配置与持久化状态接口          |
| `src/data/catalog.ts`           | 维护 12 张奇幻闪卡档案（`N` 至 `SECRET` 五个等级）及 3 个梯度卡包配置与概率权重               |
| `src/audio/soundEngine.ts`      | 封装 Web Audio API 程序化音效引擎，实现点击、摇包摩擦、撕裂递进、金光爆发、翻卡和弦与金币音效 |
| `src/store/useGameStore.ts`     | 管理金币、卡包库存、图鉴持有数、累计开箱数、灯光与静音偏好，并同步读写 `localStorage`         |
| `src/hooks/usePointerTilt.ts`   | 封装指针/触控 3D 倾斜角度（`rotateX` / `rotateY`）、反光高光坐标与眼神追踪偏移量计算          |
| `src/components/Navbar.tsx`     | 全局顶部导航栏与状态栏（页面切换、待拆包角标、金币、图鉴进度、灯光与静音开关）                |
| `src/components/PackVisual.tsx` | 3D 卡包组件，呈现哑光黑微颗粒纹理、可拖动封条、弹性形变、锯齿撕裂毛边、裂口金光与眼神追踪     |
| `src/components/CardVisual.tsx` | 3D 闪卡组件，呈现奇幻图案、全息彩虹光栅、聚光高光、烫金卡名、序列编号与稀有度等级             |
| `src/pages/HomePage.tsx`        | 首页：展示主打卡包 3D 视差、核心状态概览、补给领取及快捷跳转入口                              |
| `src/pages/ShopPage.tsx`        | 商店页：展示多档位卡包详情、稀有度权重、库存数量、购包逻辑与免费补给金币领取                  |
| `src/pages/RipPage.tsx`         | 拆卡室：核心开箱舞台，支持摇包验包、横向拖动撕开/弹性回弹、一键缓缓撕开、金光爆发与扇形翻卡   |
| `src/pages/AlbumPage.tsx`       | 图鉴页：全套卡片收集状态、稀有度筛选、单卡大屏 3D 检视、重复卡分解回收与存档重置              |

## 3. 四大核心页面与交互规范

### 3.1 首页（`HomePage`）

- **视觉焦点**：展示哑光黑主打卡包，支持随鼠标或触控移动产生 3D 倾斜与镀铝膜光泽变化，伴随缓慢呼吸悬浮动画。
- **核心功能**：提供「前往拆卡室」「逛逛商店」「领取 +500 补给」快捷操作，实时显示当前金币、待拆卡包总数与图鉴收集进度。

### 3.2 商店（`ShopPage`）

- **卡包梯度**：
- **哑光黑标准包**：入门级卡包，5 张闪卡，均衡概率。
- **全息幻彩进阶包**：提升 `SR` / `SSR` / `SECRET` 权重，强化全息衍射表现。
- **秘藏金光典藏包**：高阶卡包，末张保底 `SSR` 或 `SECRET` 逆闪异画。

- **经济循环**：支持消耗金币购包、一键领取 `+500` 免费补给金币，购入后可直接跳转至拆卡室对应卡包。

### 3.3 拆卡室（`RipPage`）

- **摇包验包**：点击「摇包验包」触发卡包高频晃动、摩擦音效与边缘稀有度光晕透视提示。
- **弹性撕裂与回弹**：
- 按住顶部 `◄ TEAR SEAL` 封条向右拖动，封口上移旋转、包体产生微拉伸与形变，撕裂处显现锯齿毛边并透出暖金光带，同时播放撕裂递进音效。
- 若拖动未达阈值即松手，封条与包体触发弹性回弹复位。
- 支持点击「缓缓撕开」自动完成平滑撕裂过程。

- **金光爆发与扇形翻卡**：封口撕开完成后触发金色光柱与爆发动画，随后 5 张闪卡展开；玩家可逐张点击翻开或点击「一键全部翻开」，新获得卡片显示 `NEW` 标识。

### 3.4 图鉴（`AlbumPage`）

- **筛选与检视**：支持按 `ALL`、`SECRET`、`SSR`、`SR`、`R`、`N` 筛选卡牌；未收集卡片显示编号与待解锁占位，已收集卡片可点击进入独立 3D 检视态，体验全息光泽与眼神追踪。
- **重复卡回收与重置**：当某张卡牌持有数量大于 1 时，可在检视面板中分解 1 张重复卡换取对应金币；支持重置本地存档。

## 4. 视觉材质、光影与动效设计

- **哑光黑微纹理与撕裂毛边**：通过双层细密噪点叠加模拟哑光黑颗粒触感，撕裂边缘采用多点折线裁切（`clip-path`）呈现不规则纤维毛边，裂口处叠加暖金色发光带。
- **深色空间光柱与烟雾**：背景层叠顶部聚光光晕、多道垂直光柱与缓慢漂浮的烟雾光斑，并支持切换暗房聚光与展厅照明氛围。
- **全息彩虹光泽与烫金文字**：卡片叠加多色渐变与动态聚光层，随指针坐标实时偏移；卡名与关键标识采用金属渐变烫金渲染，并标注 `NO. XXX / 012` 序列编号。
- **3D 倾斜与眼神追踪**：卡包与闪卡在指针移动时实时计算倾斜角度与瞳孔偏移，离开区域后平滑归位。

---

## 5. 音效系统与本地持久化

- **Web Audio 程序化音效**：首次交互后自动解锁 `AudioContext`，无需外部音频资源即可合成点击、摇包噪声滤波、撕裂音高变化、爆发和弦、稀有度差异化翻卡音与金币提示音；顶部支持全局静音切换。
- **本地存储（`localStorage`）**：自动保存金币、各档位卡包库存、单卡持有数量、累计开箱次数、静音状态与灯光模式，并配备容错兜底与存档重置功能。
