# 节气 · 二十四

浏览器里的节气拆卡收藏。玩家购买卡包、撕开封口、翻开册页，把二十四张节气收进图鉴。无账号、无服务器、无真实支付。

工程是 React + TypeScript + Vite + Tailwind CSS。卡面小景是一套工笔图片，音效用 Web Audio 合成。页面流程以本文为准，卡面、品级色、季节色、界面复用、撕开演出和翻开声音以 `docs/开发规范.md` 为准。

## 页面

顶栏固定四个入口，并提供灯光（暗房 / 展厅）和静音。拆卡室按钮在有库存时显示待拆数量。

### 首页

展示当前在售里的高爆卡包，指针移动时卡包倾斜。有库存时主按钮进入拆卡室，否则进入商店。可以打开这一包的详情。

### 商店

按卡包系列分栏。在售十套：二十四节气，以及九套画心卡。每一栏下列出低爆、中爆、高爆，并写出基础权重。购买只增加对应库存，不扣金币。买入后可以再买，也可以查看详情。

### 拆卡室

先选库存里的某一档。封着的时候可以摇包：封边按这一包已经抽定的最高品级发光。向右拖封口，未到阈值松手会回弹；也可以点「撕开封口」一次撕完。

撕开后扣掉这一包库存，五张卡写入图鉴。同一张在本包里只有第一次获得算新卡。玩家逐张翻开，或从左到右全部翻开。超稀有及以上会停住，等这一张的演出结束。

### 图鉴

列出当前卡池。多套卡包同时在售时，可以先按卡包筛选，再按品级筛选。未收集的卡只显示占位。已收集的卡可以进入检视。持有多于一张时可以分解一张，按品级增加金币。重置会清空本地进度，回到赠送一包低爆之后的图鉴页。

## 卡池与抽取

一套 24 张，每包抽 5 张，允许重复。品级分布：

- 普通：雨水、小满、小暑、处暑、白露、小雪、小寒
- 稀有：惊蛰、清明、谷雨、芒种、大暑、寒露、霜降、大雪、大寒
- 超稀有：立春、立夏、立秋、立冬
- 特级：春分、夏至、秋分
- 秘藏：冬至

权重在 `src/data/catalog.ts` 的 `BASE_WEIGHTS`：普通 46、稀有 30、超稀有 16、特级 7、秘藏 1。先抽品级，再在该品级的卡里抽一张。

低爆没有保底。中爆至少一张超稀有及以上。高爆至少一张特级或秘藏。结果达不到保底时，替换这一包里品级最低的一张。卡池里做不到的保底档不会上架。

每张卡带季节、节气小景、三候、大致日期、一句题款和一句说明。

## 存档

键名 `simplemkt.save.v1`。保存金币、各档库存、单卡持有数、累计开包次数、静音和灯光。当前页面和拆到一半的卡包不保存。缺字段或类型不对时，回到新玩家：200 金币、一包低爆、空图鉴。

旧存档里的 `standard` / `holo` / `vault` 会并入当前第一种卡包的低爆、中爆、高爆。

顶栏金币显示为无限。分解仍按品级增加存档里的金币：普通 20、稀有 60、超稀有 160、特级 420、秘藏 1000。

## 不包含

登录、后端卡池、真实货币、广告，以及外部音频资源。二十四节气的画心放在 `src/assets/solar`。卡面风格按卡包定，不收成固定几种，见 `docs/开发规范.md`。`demo/simplemkt_3d.html` 是更早的单文件草稿，不作为当前产品。
