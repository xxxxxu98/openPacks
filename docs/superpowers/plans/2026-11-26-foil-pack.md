# 银箔袋拆卡 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在浏览器里做出首页、商店、拆卡、图鉴，撕袋、抽取和存档按规格运行；图没齐的卡包不进商店。

**Architecture:** 纯函数负责抽取、撕开判定、演出时钟和存档。页面只调用这些函数。第一批 10 包的名单写在数据里。卡图文件不在本计划里生成；商店用文件是否齐全决定上架。

**Tech Stack:** Vite 6、TypeScript 5、Vitest 2。无框架。数据放 `src/catalog.ts`。

## Global Constraints

- 规格：`docs/superpowers/specs/2026-11-26-foil-pack-design.md`
- 第一批只有这 10 包：丹青、岁华、十二辰、山海、未眠、铁衣、红氍、檐滴、玄海、群芳
- 一张卡一个主体。丹青 28 张，一张对应一件原作
- 丹青金卡：《清明上河》《千里江山》。闪卡：《群虾》《洛神》
- 每张独立概率：普通 92.75%，稀有 6%，超稀有 1%，闪卡 0.2%，金卡 0.05%
- 撕口只认左右拖动。进度达到可撕长度的 2/3 才扣袋子并抽出五张
- 没到 2/3 松手，0.35 秒回到 0，不扣袋子
- 收口 0.6 秒，空拍 0.4 秒，飘出 0.8 秒，翻面 0.7 秒，落下 0.5 秒，间隔 0.4 秒
- 翻面前额外停顿：普通 0，稀有 0.3 秒，超稀有 0.45 秒，闪卡 0.6 秒，金卡 0.8 秒
- 开局：《未眠》3 袋。金币没有数量，界面是无限符号，存档不记钱
- 装饰已拥有再点只切换。封面、卡套、桌布不改变抽到的卡
- 地址带 `preview=gold` 时，下一次撕开的五张里有一张金卡。页面上没有这个按钮
- 存档读不出来就回到开局
- 没画完的包不上架。不用色块代替成品图
- 名字以后可以只改数据里的字符串。本计划先用规格里的现名
- 只有用户在当次明确要求时才 `git commit`

卡图生成不在本计划。本计划做完时，商店可以是空的，测试用一份假的文件清单证明「齐了才出现」。

```ts
export type Rarity = "common" | "rare" | "super" | "flash" | "gold";

export type CardDef = {
  id: string;
  name: string;
  rarity: Rarity;
  source?: string;
};

export const RARITY_WEIGHT: Record<Rarity, number> = {
  common: 0.9275,
  rare: 0.06,
  super: 0.01,
  flash: 0.002,
  gold: 0.0005,
};

const ORDER: Rarity[] = ["common", "rare", "super", "flash", "gold"];

export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

function pickRarity(random: () => number): Rarity {
  const x = random();
  let acc = 0;
  for (const rarity of ORDER) {
    acc += RARITY_WEIGHT[rarity];
    if (x < acc) return rarity;
  }
  return "common";
}

export function rollFive(cards: CardDef[], random: () => number): CardDef[] {
  return Array.from({ length: 5 }, () => {
    const rarity = pickRarity(random);
    const pool = cards.filter((card) => card.rarity === rarity);
    if (pool.length === 0) throw new Error(`档位没有卡: ${rarity}`);
    return pool[Math.floor(random() * pool.length)];
  });
}

export function withPreviewGold(drawn: CardDef[], cards: CardDef[]): CardDef[] {
  const gold = cards.find((card) => card.rarity === "gold");
  if (!gold) throw new Error("这包没有金卡");
  const next = drawn.slice();
  next[0] = gold;
  return next;
}
```

```ts
export const TEAR_THRESHOLD = 2 / 3;

export function tearProgress(dragPx: number, trackPx: number): number {
  if (trackPx <= 0) return 0;
  return Math.min(1, Math.max(0, dragPx / trackPx));
}

export function isOpened(progress: number): boolean {
  return progress >= TEAR_THRESHOLD;
}
```

从左往右拖时 `dragPx` 为正。从右往左拖时，调用方先把位移取成向撕开方向的正数再传入。竖直位移不传入。

```ts
export type OwnedCard = { id: string; name: string };

export type SaveData = {
  packs: Record<string, number>;
  owned: Record<string, number>;
  names: Record<string, string>;
  cosmetics: { cover: string[]; sleeve: string[]; cloth: string[] };
  equipped: { cover: string; sleeve: string; cloth: string };
  current: { packId: string; cards: OwnedCard[]; shown: number } | null;
};

export function freshSave(): SaveData {
  return {
    packs: { weimian: 3 },
    owned: {},
    names: {},
    cosmetics: { cover: ["default"], sleeve: ["plain"], cloth: ["default"] },
    equipped: { cover: "default", sleeve: "plain", cloth: "default" },
    current: null,
  };
}

export function loadSave(raw: string | null): SaveData {
  if (!raw) return freshSave();
  try {
    const parsed = JSON.parse(raw) as SaveData;
    if (!parsed.packs || typeof parsed.packs.weimian !== "number") return freshSave();
    return parsed;
  } catch {
    return freshSave();
  }
}

export function commitOpen(save: SaveData, packId: string, cards: OwnedCard[]): SaveData {
  const left = save.packs[packId] ?? 0;
  if (left < 1) throw new Error("没有这个袋子");
  return {
    ...save,
    packs: { ...save.packs, [packId]: left - 1 },
    current: { packId, cards, shown: 0 },
  };
}

export function finishOpen(save: SaveData): SaveData {
  if (!save.current) return save;
  const owned = { ...save.owned };
  const names = { ...save.names };
  for (const card of save.current.cards) {
    owned[card.id] = (owned[card.id] ?? 0) + 1;
    names[card.id] = card.name;
  }
  return { ...save, owned, names, current: null };
}

export function buyPack(save: SaveData, packId: string): SaveData {
  return { ...save, packs: { ...save.packs, [packId]: (save.packs[packId] ?? 0) + 1 } };
}

export function equip(save: SaveData, kind: "cover" | "sleeve" | "cloth", id: string): SaveData {
  const owned = save.cosmetics[kind].includes(id)
    ? save.cosmetics
    : { ...save.cosmetics, [kind]: [...save.cosmetics[kind], id] };
  return { ...save, cosmetics: owned, equipped: { ...save.equipped, [kind]: id } };
}
```
